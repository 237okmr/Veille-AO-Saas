# Backend Apps Script (copie de référence)

Ces 25 fichiers `.gs` sont une copie fidèle du projet Apps Script « Script_Hub_Veille_AO », exportée le 2026-11-08 depuis l'éditeur Google. Le projet réel reste celui de l'éditeur : ce dossier sert d'historique et de filet de sécurité (comparaison, retour arrière).

Règles de mise à jour : après chaque modification collée dans l'éditeur, copier le fichier modifié ici sous le même nom, puis commiter. Ne jamais y déposer de clé API ni de secret : ils vivent dans les propriétés du script.

Non inclus : le manifeste `appsscript.json` (masqué par défaut dans l'éditeur).
